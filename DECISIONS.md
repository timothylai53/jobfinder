## Skill groups and soft skills (2026-11-07)

| # | Decision | Reason |
|---|---|---|
| 52 | **"One of these" groups.** Within a clause, skills separated only by `/`, `|`, `,`, `;`, "or" or "and/or" form a run. A run is **one requirement, met by any member**, when its separators include `/`, `|` or "or", or when the text just before it says "at least one / one of / any of / either / one or more of", or when it is followed by "or equivalent / similar / other". A comma-only list without such a signal ("JavaScript, HTML and CSS") stays as separate requirements. "At least one (1) year" is not an alternatives signal. In the breakdown a group is shown as "One of: C# / Java / JavaScript (or equivalent)", with the matched skill and its evidence (e.g. "Java, from B2"). | Your request. Recruiters write alternatives with slashes and "or". A plain comma list usually means "all of these". |
| 53 | **"Or equivalent"** lets a skill of the same kind satisfy the requirement, shown as "equivalent: PostgreSQL, from B2".<br>• Within a category: by default, "same kind" means the same skill category.<br>• Families: relational databases (SQL, MySQL, PostgreSQL, MS SQL, Oracle, SQLite) and NoSQL stores (MongoDB, Redis, Firebase, DynamoDB, Elasticsearch) are separate families, so Firebase does **not** count for "MS SQL / MySQL or equivalent".<br>• Never via equivalence: soft, concept, process and other skills. | "Or equivalent" literally invites an equivalent skill. On the real job, without the families, Firebase was being accepted as an equivalent of MySQL, which is wrong. |
| 54 | **Soft skills are not scored by default.** Skills in the dictionary's `soft` category are taken out of the required/preferred points and listed under "Soft skills (not scored)", each with met/not met. The setting is Settings → Scoring → **Score soft skills** (default off, `ScoringConfig.score_soft_skills`). When it's on, they count like any other skill. | Your request. Soft skills are claimed, not evidenced, and they often decided scores on JDs that list many of them. |
